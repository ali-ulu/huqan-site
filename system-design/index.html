04 / Honest boundaries

What the architecture does not promise.

Trustworthy system design makes failure and coverage boundaries visible. These constraints are part of the product contract, not footnotes.

01

No hook, no gate coverage.

The guard only governs an action when the connected client invokes it before execution. An agent or tool path that bypasses the adapter is not covered by that gate.

02

Deployment boundary matters.

The Approval Authority has installers for Windows, Linux and macOS, with Windows the most field-tested. Containers, virtual machines and remote hosts are not supported deployment targets.

03

A receipt is not universal truth.

A Trust Receipt records what a specific HUQAN boundary evaluated and decided under specific inputs and policy. It does not prove that an AI claim is universally true or that an operator is honest.

04

It complements other controls.

HUQAN does not replace IAM, application security, infrastructure security, sandboxing or organizational governance. A signed plugin is not automatically sandboxed.
