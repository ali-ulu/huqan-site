# huqan-site
Official Huqan landing page — deterministic trust infrastructure for AI systems.

## Local demo preview

From this directory, start a local static server:

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173/preview.html](http://localhost:4173/preview.html) in a browser. The preview page focuses the interactive demo while keeping a link back to the full landing page.
